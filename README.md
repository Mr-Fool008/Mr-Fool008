## Featured Projects

### [pfSense Firewall Home Lab](https://github.com/Mr-Fool008/pfsense-firewall-home-lab)

Built a segmented VirtualBox network with **pfSense, Kali Linux, and Ubuntu** to practice firewall administration, routing, DHCP/DNS, packet analysis, and controlled traffic filtering.

Highlights:
- Configured WAN/LAN segmentation and firewall policy
- Diagnosed an **Unbound DNS failure** from service logs
- Used Wireshark to validate traffic before and after blocking
- Documented routing, DNS, firewall-rule order, and troubleshooting methodology

---

### [Wazuh SIEM & File Integrity Monitoring Lab](https://github.com/Mr-Fool008/wazuh-siem-fim-lab)

Built a Wazuh SIEM/XDR lab for monitoring a Windows endpoint and detecting real-time file changes.

Highlights:
- Deployed and enrolled a monitored endpoint
- Configured **real-time File Integrity Monitoring**
- Generated controlled file creation, modification, and deletion events
- Investigated Wazuh alerts and integrity evidence

---

### [Network Security Analyzer & Algorithmic NIDS](https://github.com/Mr-Fool008/network-security-analyzer)

A Python-based packet analyzer and network intrusion detection project that combines security monitoring with core data structures and algorithms.

Highlights:
- Packet-volume tracking and port-scan detection
- SYN-flood detection and sliding-window rate analysis
- Top-K talker analysis with heaps
- Graph-based network relationship analysis
- Structured JSON/CSV output for SIEM-style workflows

---

### [Lazarus / APT38 Case Study](https://github.com/Mr-Fool008/lazaraus-apt38-case-study)

A threat-focused case study documenting Lazarus Group / APT38 activity, tactics, techniques, and defensive analysis.
